# Project: SideTap – Task & Service Exchange App (MVP)

## 1. MVP Goal
Allow users to post small tasks, offer services, and communicate—all within a mobile app.

## 2. Target Users
- Students needing side income.
- Freelancers offering help (e.g., tutoring, design, errands).
- Local people needing fast help (laundry pickup, setup, academic help, etc.).

## 3. Core Features (MVP Only)

### a. User Registration / Login
- Google Sign-In or Email/Password
- Basic profile: name, age, skill tags, city/school.

### b. Post a Task
- Fields: Title, Description, Budget, Category, Location, Deadline

### c. Offer a Service (Gig Post)
- Fields: Service Name, Skills, Price, Availability

### d. Browse/Search Tasks or Gigs
- Filters: Location, Budget, Category
- Sort: Newest, Closest, Budget (high-low)

### e. In-App Chat
- Task/Gig-related messaging using Firebase Realtime DB or Firestore

### f. Ratings (Optional MVP+)
- 5-star reviews, simple comment system after task completion

## 4. Suggested Tech Stack

| Layer      | Toolset                        |
|------------|-------------------------------|
| Frontend   | Flutter OR React Native       |
| Backend    | Firebase (Auth + Firestore)   |
| Chat       | Firebase Realtime DB          |
| Hosting    | Firebase Hosting or Vercel    |
| Payment    | Manual (GCash link) → Stripe Later

## 5. Monetization Plan

- 5–10% commission per task transaction
- Featured Gig Promotion (e.g., ₱49 for 7 days)
- Premium Freelancer Badge (₱99/month = unlimited posts, highlight)

## 6. Launch Plan

- Pilot: Launch in 1 campus or barangay
- Get 20 test users: friends, students, freelancers
- Iterate weekly based on real usage
- Expand via referrals, FB groups, Discord, school communities

## Notes:
